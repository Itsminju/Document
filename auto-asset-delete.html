상품 이미지 반려·삭제 화면 기획

01배경과 목적

자동 생성 소재(비즈보드 상품, 채팅리스트/톡피드 AI)는 재생성이나 반려 뒤에도 이전 이미지와 승인 정보가 남아, 검수 전 이미지가 송출되거나 쓰지 않는 이미지가 쌓일 수 있습니다.
또 모비온 반려 사유는 직접 입력이라 사유별 통계를 낼 수 없습니다. 이번 변경으로 반려 사유를 서브 사유 코드로 받고, 사유별 처리 기준(O 보관 / X 즉시 삭제)에 따라 이미지를 정리합니다.

02삭제 조건

구분as-isto-be (파란색 = 변경)
소재 재생성
  • 같은 PCODE라도 생성 4개월 후 재생성
  • 기존 이미지 삭제, 새 이미지 파일명 +1 (IMG_DATA는 1개만 조회)
  • 승인 정보(BIZ_STATE)는 그대로 둠
  • 생성 1개월 후 재생성
  • 기존 이미지 삭제, 새 이미지 파일명 +1 (동일)
  • 재생성일 이전 승인 정보는 모두 99 자동 반려 (사유: 소재 신규 생성으로 인한 자동 반려)
  • 이미지 삭제와 승인 정보 변경은 한 트랜잭션으로 처리.
    02가 남으면 검수 전 이미지가 송출됨
모비온 검수
상품화 이미지 화면
  • 반려 처리만 함
  • 내부승인: 별도 처리 없음 (재생성 때 이미 1개만 남음)
  • 모비온 반려(99): 선택한 사유 코드의 O/X에 따라 보관 또는 즉시 삭제
  • 승인 코드 99, 사유는 팝업에서 선택한 사유 코드로 저장
카카오 검수 완료
  • 검수 결과(승인/반려)만 반영
  • 승인(02): 별도 처리 없음
  • 카카오 반려(98): 사유 원문의 "[분류] 사유명"을 서브 사유 코드에 매칭해 O 보관 / X 즉시 삭제
  • 사유가 여러 개면 O가 하나라도 있을 때 보관.
    코드표에 없는 새 사유는 분류될 때까지 보관
  • 승인 코드 98, 사유는 카카오에서 받은 사유로 저장
삭제 API없음
  • 호출: 카카오 검수 완료, 모비온 반려 처리 직후
  • 전달: PCODE, 검수 결과(02 / 98 / 99), 반려 사유 코드(복수 가능)
  • 02는 처리 없음.
    98 / 99는 코드별 통계 반영 → O면 이미지를 반려 기록으로 이동, X면 삭제
  • 통계 반영 전에는 이미지 삭제 불가
반려 팝업
모비온 반려
  • 사유 직접 입력 (최대 100자).
    표현이 제각각이라 통계 불가
  • 드롭리스트 개에서 선택 (기타 선택 시 입력칸, 최대 100자)
  • 사유 미선택 시 [확인] 비활성
  • 각 항목을 카카오 서브 사유 코드와 연결해 같은 코드로 통계
과거 소재 삭제없음
  • 매일, 생성일 기준 90일 지난 소재 삭제 (승인 소재 포함)

03변경 범위

바뀌는 것

  • 반려 팝업: 직접 입력 → 반려 사유 드롭리스트 개 (기타 선택 시 직접 입력)
  • 반려 시 이미지 처리: 사유별 O 보관 / X 즉시 삭제
  • 재생성 시 이전 승인 정보 → BIZ_STATE_CODE 99 자동 반려
  • 반려사유 컬럼: 선택한 사유명 표시 (사유 코드는 화면에 노출하지 않음)
  • 생성일 기준 90일 지난 소재 매일 삭제 (승인 소재 포함)

그대로인 것

  • 목록·필터·검수 현황 요약표 구성
  • 송출 로직: BIZ_STATE_CODE 02이면 IMG_DATA 이미지 송출
  • 상품당 이미지 1개 유지 (MOB_SHOP_KAKAO_BIZ_IMG_DATA)
  • 승인(02) 시 별도 처리 없음

06결정 사항과 남은 일

확정

  • 상품당 이미지·승인 정보는 마지막 1장 기준
  • 재생성 시 기존 이미지 삭제, 이전 승인 정보 99 자동 반려
  • 서브 사유 코드표의 O/X를 최종 처리 기준으로 사용
  • 모비온 반려도 카카오 반려와 같은 O/X 규칙 적용
  • 반려 사유는 드롭리스트로 받고, 기타만 직접 입력 (최대 100자)
  • 생성일 기준 90일 지난 소재는 승인 소재 포함 매일 삭제
  • 30% 초과 알림은 카카오 반려(98) 비율 기준
  • 송출 불가 광고주·송출 불가 카테고리는 생성 조건과 자동 반려 조건을 따름.
    운영자가 수동으로도 송출 불가 광고주·카테고리를 등록할 수 있음
  • O 보관 이미지는 기간 제한 없이 계속 보관
  • 반려 사유는 기존과 같은 위치(STATE_COMMENT)에 계속 저장

남은 일

  • 90일 삭제 시 STATE 변경 코드
  • 자동 반려를 요약표에서 분리 표시할지
  • 9월 O/X 이미지 단위 재집계
