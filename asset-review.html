소재 심사 팝업 개선

01배경과 목적

  • 기존 소재 심사는 배치 조건만으로 동작
  • 매일 정해진 시간에 최신순으로 정해진 건수만 심사 대상으로 선정
  • 특정 광고주를 먼저 심사받게 할 방법 없음

02개발 범위

  • [심사 요청] 버튼 추가
    • 위치: 비즈보드 (상품) · 채팅리스트/피드 · 채팅리스트/피드(AI)
    • 클릭 시: 소재 심사 팝업 (심사 요청 / 예약 내역 탭)
    • 특정 광고주에 지정 개수만큼 소재 심사 우선권 부여
  • 광고주 단위로 심사 요청 취소 가능
  • 채팅리스트 두 메뉴는 팝업 설정과 예약 내역 공유
  • 타입별 심사 요청 총 발송 개수 GUI 수정 가능

05결정 사항과 남은 일

확정

  • 심사 요청 · 예약 내역을 팝업 1개의 탭으로 통합, 기본 탭은 심사 요청
  • [소재 심사] 버튼 메뉴: 비즈보드 (상품) · 채팅리스트/피드 · 채팅리스트/피드(AI)
  • 버튼 위치: 비즈보드 [+ 광고 생성] 오른쪽, 채팅리스트 [반려] 오른쪽
  • 비즈보드: 총 발송 개수 최대 4,000개, 지정 광고주 우선 + 그 외 최신 생성순 채움
  • 채팅리스트: 총 발송 개수 최대 1,500개, 지정 광고주 AI 소재 몫 우선 보장 → 채팅리스트/피드 소재 → 그 외 AI 최신 생성순
  • 채팅리스트 두 메뉴는 같은 팝업 · 같은 예약 내역 공유
  • 즉시 발송 없음, 평일 예약 발송만 가능 (날짜만 지정)
  • 공휴일 데이터: 최고관리자에서 관리
  • 합계 영역은 발송 개수 합계만 표시
  • 요청별 총 발송 개수 입력 가능 (기본값 = 최대값)
  • 발송 개수 합계는 입력 단계에서 총 발송 개수 이하로 제한
  • 예약 내역: 광고주 단위 행, 상세 화면 없음, 기본 조회 기간 당일
  • 컬럼: 광고주 | 발송 개수 | 발송 예정 일시 | 요청자 / 요청 일시 | 취소자 / 취소 일시 | 발송 취소
  • 발송 취소 컬럼은 버튼만 노출
