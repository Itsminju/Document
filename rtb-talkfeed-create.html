채팅리스트/피드(AI) 화면설계서

메뉴: 이미지 검수 > 채팅리스트 / 피드(AI)
목적: 매일 배치로 AI 생성된 850×850 배너 소재를 검수(내부승인/반려)
URL: /image/aiCreative (확정 필요)
링크 검증 중…

1[상단 현황]

a. 승인상태별 이미지 수와 광고주 수를 표로 보여준다.
b. 컬럼: 전체 / 대기 / 승인 / 모비온 반려 / 카카오 반려 (기존 채팅리스트/피드와 동일).
c. 값 예시: "이미지 수 N건", "광고주 수 N개".
d. 집계 기준 확인 필요: 상단 기간(2-1) 필터 반영 여부, '내부승인' 상태 컬럼 추가 여부.

2[검색 조건]

a. 기간과 승인상태로 목록을 조회한다.
b. 조건 변경 시 목록과 상단 현황을 새로 불러온다.

2-1[기간 선택 · 검색]

a. 기본값: 이번 달 1일 ~ 말일.
b. 프리셋: 오늘 / 어제 / 이번달 / 전월 / 전전월 / 최근 7일 / 최근 30일 / 최근 90일 / 최근 180일 / 사용자 선택.
c. [검색] 클릭 시 선택한 기간으로 조회한다.

2-2[승인상태 필터]

a. 옵션: 전체 / 대기 / 내부승인 / 승인 / 모비온 반려 / 카카오 반려.
b. 기본값: 대기.
c. 라디오 클릭 즉시 조회한다(별도 검색 버튼 없음).

3[일괄 처리]

a. 목록에서 체크한 소재의 상태를 한 번에 변경한다.
b. 선택된 소재가 없으면 "변경할 이미지를 선택해 주세요." 안내 후 중단한다.
c. 선택한 소재 ID와 광고주 ID를 함께 모달로 전달한다.

3-1[내부승인]

a. 클릭 시 내부승인 확인 모달을 연다(500×200).
b. 확인 시 선택 소재를 '내부승인' 상태로 변경한다.
c. 내부승인 이후 카카오 심사 요청 · '승인'/'카카오 반려' 상태 반영 방식 확인 필요.

3-2[반려]

a. 클릭 시 반려 모달을 연다(500×450).
b. 반려 사유를 입력하면 선택 소재를 '모비온 반려' 상태로 변경하고 사유를 저장한다.
c. 저장된 사유는 목록의 반려사유(5-10)에 노출된다.
d. 반려 사유 템플릿 제공 여부 확인 필요 (반려타입 컬럼은 이 화면에서 제외됨).

4[목록 도구]

a. 목록 표시 방식과 내보내기를 설정한다.

4-1[컬럼 설정]

a. 목록에 보일 컬럼을 켜고 끈다.
b. 기존 채팅리스트/피드와 같은 공통 컬럼 설정 기능을 쓴다.

4-2[검색어 검색]

a. 검색어 입력 후 [검색] 클릭 또는 Enter로 조회한다.
b. 검색 대상 컬럼 확인 필요 (예: 광고주ID, 광고주명, 사이트명, 광고문구).

4-3[보기 개수]

a. 옵션: 100개 / 250개 / 500개씩 보기.
b. 기본값: 100개.
c. 변경 즉시 다시 조회한다.

4-4[엑셀 다운로드]

a. 현재 검색 조건(기간 · 승인상태 · 검색어)으로 목록을 엑셀 파일로 받는다.
b. 엑셀 컬럼은 화면 목록과 같다.
c. 배너이미지 컬럼 포함 방식 확인 필요 (기존 화면은 엑셀에 배너이미지 없음 → URL 텍스트로 넣을지).

5[소재 목록]

a. AI 생성 소재 1건이 1행이다.
b. 맨 앞 체크박스로 일괄 처리(3) 대상을 고른다. 헤더 체크박스는 전체 선택.
c. NO는 현재 페이지 기준 순번이다.
d. 기본 정렬 확인 필요 (예: 생성일자 최신순).

5-1[승인상태]

a. 상태를 색 버튼으로 표시한다: 대기(노랑) / 내부승인 / 승인 / 모비온 반려 / 카카오 반려.
b. 배치로 생성된 직후 상태는 '대기'.

5-2[광고주 정보]

a. 광고주ID · 광고주명 · 카테고리를 표시한다.
b. 값은 배치 대상 광고주 정보에서 가져온다.
c. 카테고리 표기 예시: "대분류>중분류>소분류".

5-3[사이트명]

a. 광고주 API에서 받은 on 상태 소재그룹의 사이트명을 표시한다.
b. 생성 시점 값으로 저장되어, 이후 소재그룹이 바뀌어도 그대로 유지된다.
c. on 소재그룹이 여러 개일 때 어느 그룹 값을 쓸지 확정 필요 (그룹별 생성 / 대표 1개).

5-4[프로필 로고]

a. 광고주 API의 on 소재그룹 프로필 로고를 썸네일로 표시한다.
b. 클릭 시 원본 크기 미리보기 팝업(600×600)을 연다.

5-5[배너이미지]

a. AI로 생성한 850×850 배너를 썸네일로 표시하고, 아래에 사이즈 타입 'TP 09'를 적는다.
b. 클릭 시 미리보기 팝업(850×850)을 연다.

5-6[소재 광고문구]

a. 광고주 API의 on 소재그룹 광고문구를 표시한다.
b. 긴 문구도 줄바꿈해서 전부 보여준다.

5-7[랜딩URL]

a. 상품 수집 시 저장한 상품별 URL을 표시한다.
b. 클릭 시 새 탭으로 연다. 마우스를 올리면 전체 URL을 툴팁으로 보여준다.

5-8[CTA 정보]

a. 광고주 API의 on 소재그룹 CTA 문구를 표시한다.
b. 값 예시: "바로가기".

5-9[생성일자 · 최종업데이트일]

a. 생성일자: 배치가 소재를 만든 시각.
b. 최종업데이트일: 상태 · 사유 · 메모가 마지막으로 바뀐 시각. 변경 이력이 없으면 비워 둔다.
c. 표기 형식: YYYY-MM-DD HH:MM:SS.

5-10[반려사유]

a. 반려(3-2) 시 입력한 사유를 읽기 전용 텍스트 영역에 표시한다.
b. 카카오 반려 사유를 이 칸에 함께 노출할지 확인 필요.

5-11[비고]

a. 검수자가 소재별 메모를 남긴다.
b. 입력 후 [입력] 클릭 시 저장하고 "정상 처리 하였습니다." 안내 후 목록을 새로 고친다.
c. 승인상태와 관계없이 언제든 수정할 수 있다.

6[페이징]

a. 보기 개수(4-3) 단위로 페이지를 나눈다.
b. «, » 로 이전 · 다음 페이지로 이동하고, 현재 페이지는 파란색으로 표시한다.
c. 페이지 이동 시 검색 조건을 그대로 유지한다.
