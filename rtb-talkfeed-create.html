채팅리스트/피드(AI) 화면설계서

메뉴: 모비센스 > 이미지 검수 > 채팅리스트 / 피드(AI)
목적: 매일 배치로 AI 생성된 850×850 배너 소재를 검수(내부승인/반려)

1[상단 현황]

a. 승인상태별 이미지 수와 광고주 수 노출
b. 컬럼: 전체 / 대기 / 내부승인 / 승인 / 모비온 반려 / 카카오 반려
   b-1. 기존 채팅리스트/피드와 동일하며, '내부승인' 컬럼 추가
c. 값 예시: "이미지 수 N건", "광고주 수 N개"
d. 집계 기준: [2] 조회 기간 조건을 따라감

2[검색 조건]

a. 기간과 승인상태로 목록 조회
   a-1. 기간은 생성일, 최근 업데이트일 2가지로 조회 가능
b. 조건 변경 시 목록과 상단 현황 새로 조회

3[일괄 처리]

a. 목록에서 체크한 소재의 상태 일괄 변경
b. 선택된 소재가 없는 경우 얼럿
   b-1. "변경할 이미지를 선택해 주세요."

3-1[내부승인]

a. 클릭 시 내부승인 확인 모달 오픈 (500×200)
b. 확인 시 선택 소재를 '내부승인' 상태로 변경
   b-1. 다량의 소재를 일괄 처리하는 경우 필요시 로딩 스피너 사용

3-2[반려]

a. 클릭 시 반려 모달 오픈 (500×450)
b. 반려 사유를 입력 후 [확인] > 상태 변경 및 사유 저장
c. 저장된 사유는 목록의 반려사유(5-10)에 노출

4[목록 도구]

a. 목록 표시 방식 설정 및 내보내기

4-1[컬럼 설정]

a. 목록에 노출할 컬럼 선택(ON/OFF)
b. 기존 채팅리스트/피드의 공통 컬럼 설정 기능과 동일

4-2[검색어 검색]

a. 검색어 입력 후 [검색] 클릭 또는 Enter 시 조회
b. 검색 대상: 광고주ID, 광고주명

4-3[보기 개수]

a. 옵션: 100개 / 250개 / 500개씩 보기
b. 기본값: 100개
c. 변경 시 즉시 재조회

4-4[엑셀 다운로드]

a. 현재 검색 조건(기간 · 승인상태 · 검색어)으로 목록을 엑셀 파일로 다운로드
b. 엑셀 컬럼은 화면 목록과 동일
c. 이미지(배너이미지, 프로필 로고)는 이미지 대신 이미지 주소(URL) 제공

5[소재 목록]

a. AI 생성 소재 1건당 1행 노출
b. 맨 앞 체크박스로 일괄 처리(3) 대상 선택
   b-1. 헤더 체크박스는 전체 선택
c. NO는 현재 페이지 기준 순번
d. 기본 정렬: 생성일자 최신순

5-1[승인상태]

a. 상태를 색 버튼으로 노출: 대기(노랑) / 내부승인 / 승인 / 모비온 반려 / 카카오 반려
b. 배치로 생성된 직후 상태는 '대기'

5-2[광고주 정보]

a. 광고주ID · 광고주명 · 카테고리 노출
b. 카테고리 표기 예시: "대분류>중분류>소분류"

5-3[사이트명]

a. 광고주 정보(adMember)의 사이트명 노출
b. 생성 시점 값으로 저장되며, 이후 광고주 정보가 변경되어도 유지

5-4[프로필 로고]

a. 광고주 정보(adMember)의 프로필 로고를 썸네일로 노출
b. 클릭 시 원본 크기 미리보기 모달 오픈 (600×600)

5-5[배너이미지]

a. AI 생성 850×850 배너를 썸네일로 노출하고, 하단에 사이즈 타입 'TP 09' 표기
b. 클릭 시 미리보기 모달 오픈 (850×850)

5-6[소재 광고문구]

a. 소재그룹 카피문구(2) 노출
b. 긴 문구는 줄바꿈하여 전체 노출

5-7[랜딩URL]

a. 상품 수집 시 저장된 상품별 URL 노출
b. 클릭 시 새 탭으로 오픈
   b-1. 마우스 오버 시 툴팁으로 전체 URL 제공

5-8[CTA 정보]

a. 광고주 정보(adMember)의 CTA 문구 노출
b. 값 예시: "바로가기"

5-9[생성일자 · 최종업데이트일]

a. 생성일자: 배치가 소재를 생성한 시각
b. 최종업데이트일: 상태 · 사유가 마지막으로 변경된 시각
   b-1. 변경 이력이 없는 경우(최초) 빈값
c. 표기 형식: YYYY-MM-DD HH:MM:SS

5-10[반려사유]

a. 반려(3-2) 시 입력한 사유를 읽기 전용 텍스트 영역에 노출
b. 카카오 반려 사유 발생 시 카카오 반려 사유로 덮어쓰기

6[페이징]

a. 보기 개수(4-3) 단위로 페이지 구분
b. «, » 클릭 시 이전 · 다음 페이지로 이동하며, 현재 페이지는 파란색으로 표시
c. 페이지 이동 시 검색 조건 유지

7[생성 조건]

a. 검색 조건 영역의 [자동 반려 조건] 버튼 옆에 노출
b. 클릭 시 '생성 대상 광고주' 팝업 오픈
c. 소재를 생성하는 광고주의 순서와 제외 기준 조회용 팝업
d. [x] 버튼 클릭시 팝업 닫힘

7-1[광고주 리스트 (생성 순서)]

a. 팝업 오픈 시 기본 노출 탭
b. 해당 리스트의 순서 대로 생성
c. 조회 조건:
   c-1. 드롭박스 : 최근생성일(디폴트), 다음 생성 예정일
   c-2. [검색] 클릭시 조회
d. 보기 개수: 100개 / 250개 / 500개씩 보기
   d-1. 기본값 100개, 변경 시 즉시 재조회
e. [엑셀]: 현재 조회된 테이블 그대로 엑셀로 데이터 다운
   e-1. 파일명: talkfeedcreative_YYYYMMDD
f. 컬럼: 순번 / 광고주ID / 광고주명 / 카테고리 / 최근 생성일 / 다음 생성 예정일 / 비고
   f-1. 최근 생성일 · 다음 생성 예정일이 없는 경우 '—' 노출
g. 비고
   g-1. 제외 카테고리
        : 광고주 카테고리가 생성 제외 카테고리에 해당
   g-2. 생성 제외 광고주
   g-3. 신규 광고주: 새로 등록된 광고주
   g-4. 해당 없는 경우 '—' 노출

7-2[생성 제외 카테고리]

a. 소재를 생성하지 않는 카테고리를 구분별로 노출
b. 컬럼: 구분 / 소카테고리
c. 구분: 성인·의료 / 성인 콘텐츠·용품 / 담배 / 금융·투자 / 사행·운세
d. 자동 반려 조건의 '송출 불가 카테고리'와 같은 목록 (한쪽 변경 시 동일하게 반영 필요)

7-3[생성 제외 광고주]

a. 소재 생성에서 제외된 광고주 목록 노출
b. 컬럼: 광고주ID / 광고주명
c. 이 목록에 있는 광고주는 광고주 리스트(7-1)의 비고에 '생성 제외 광고주'로 노출
